## Overview

**BlueSky Engine Simulate Editor** is a community-made editing and simulation tool inspired by the systems behind Sky: Children of the Light.

The goal is to provide a flexible environment for experimenting with simulated game physics, editing maps, and creating custom elements.

Whether you're exploring engine behavior or building something entirely new, this project is a playground for your imagination.

## Features

* **Physics Simulation** — Experiment with Bluesky Engine-inspired physics and behavior.
* **Custom Meshes** — Add and work with custom mesh objects.
* **Map Editing** — Create, edit, and experiment with maps.
* **Teleport Points** — Place custom TP points for navigation and testing.
* **More Possibilities** — An evolving project with room for new tools and features.

*Features may change as development continues.*
