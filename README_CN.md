## 项目简介

**BlueSky Engine Simulate Editor** 是一个面向《光·遇》的社区自制编辑器，旨在提供用于实验、编辑和探索游戏环境的工具。

与从零重新实现物理系统的项目不同，本编辑器的物理相关功能直接使用 **Bluesky Engine 原始源码**，而不是自行重新编写一套物理引擎。

本项目致力于提供灵活的编辑环境，让用户能够探索游戏环境、创建自定义内容，并尝试更多可能性。

## 功能特色

* **原版引擎物理** — 物理相关功能使用 Bluesky Engine 原始源码，而非独立重写物理系统。
* **自定义 Mesh** — 添加和尝试自定义网格模型。
* **地图编辑** — 创建、编辑和探索地图环境。
* **传送点编辑** — 添加和管理自定义传送点（TP Points）。
* **持续开发** — 随着项目发展，逐步加入更多工具和功能。
