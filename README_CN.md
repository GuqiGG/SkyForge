## ✦ 项目简介

**SkyForge** 是一个面向《光·遇》的社区自制编辑器，用于探索游戏环境、编辑地图和尝试自定义内容。

本项目并非从零重新实现物理系统，而是**直接使用 Bluesky Engine 原始源码**实现相关物理功能。

项目的目标很简单：提供一个灵活的编辑环境，让你能够探索游戏环境、添加自定义 Mesh、编辑地图，并尝试创建传送点。
